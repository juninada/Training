# 航空管制 無線交信 聴取訓練システム

管制官が無線（R/T）で受ける交信を、実際の運用に近いノイズ環境下で聞き取り、
「相手は何を話しているのか」「自分はそれに対して何を返すべきか」を判断する
訓練を行うための、非公式のブラウザ学習ツールです。

ビルド不要の静的な HTML / CSS / JavaScript のみで構成されており、
音声の加工はすべてブラウザの Web Audio API 上でリアルタイムに行われます
（外部サーバーへの音声アップロードは発生しません）。

## 使い方

1. 任意の静的サーバーで配信して開きます（`file://` では `fetch` 系の制約が
   出る場合があるため、簡易サーバーの利用を推奨します）。

   ```bash
   npx http-server -p 8080 -s
   # → http://localhost:8080/ を開く
   ```

2. 左パネル「音声ライブラリ」から訓練用の音声ファイル（wav / mp3 等）を
   アップロードします。複数登録して切り替えながら訓練できます。
3. 任意で「模範解答の登録」に、聞き取り正解（送信内容）と模範応答（管制官の
   返答例）を入力しておくと、後で自己採点に使えます。
4. 右パネル「ノイズ・エフェクト卓」のゲージで各エフェクトの強度（0〜100%）を
   調整します。
5. 中央の PLAY ボタンで、設定した強度のノイズを重ねた状態で音声が再生されます。
6. 再生が終わると「Q1. 相手は何を話しているか？」「Q2. 自分は何を返すべきか？」
   の回答欄が表示されるので記入し、「解答を確認する」で模範解答と照合、
   ◎/△/✕ で自己判定します（本日の訓練ログに記録されます）。
7. よく使うノイズの組み合わせは「お気に入り」に最大3つまで保存でき、
   訓練中にワンクリックで呼び出せます（ブラウザの localStorage に保存され、
   再読み込み後も保持されます）。

## ノイズエフェクト

| エフェクト | 内容 |
| --- | --- |
| マスク籠り | 酸素マスク越しのような低域寄りのこもった声を、ローパス＋共鳴フィルタで再現 |
| 無線ノイズ | 無線機の帯域制限（300〜3400Hz）・ヒスノイズ・軽いクリップ歪みをドライ音とクロスフェード |
| 風切り音 | フィルタ処理したノイズにゆっくりとしたゲイン変動（突風）を加えた環境音 |
| 英語の訛り（簡易再現） | 再生速度・ピッチをゆっくり揺らすことで訛り・拙い抑揚を疑似的に再現する近似演出です（実際のアクセント変換ではありません） |
| 通信不良の音声途切れ | 強度に応じてランダムな瞬断（ゲイン低下）を挿入し、電波状況不良を再現 |

各エフェクトは PLAY を押した時点のゲージ値がそのまま適用されます
（再生中にゲージを動かしても、その回の再生には反映されません）。

## ディレクトリ構成

```
index.html          画面構成
css/style.css        JASDF管制卓を意識したダーク／レーダーグリーン基調のUI
js/noise.js           ノイズバッファ生成（white / pink / brown）
js/audio-engine.js    Web Audio 上のエフェクトチェーンと再生制御
js/presets.js         お気に入り（最大3件）のlocalStorage永続化
js/app.js             画面全体の状態管理・イベント配線
```

## 免責事項

本システムは聴取訓練を目的とした非公式の学習支援ツールであり、
実際の管制業務・機体運用・公式機関とは関係ありません。
