# 管制通信聴取訓練システム（ATC Comm Reception Trainer）

航空自衛隊の管制官を想定した、無線通信の聴取・応答判断トレーニング用ウェブアプリです。
アップロードした音声にノイズエフェクトを任意の強度で適用して再生し、「相手は何を話しているか」
「自分は何を返すべきか」を訓練できます。

外部サービスやビルド不要の静的サイトです（Web Audio API のみで動作）。

## 使い方

任意の静的サーバーで配信して開いてください。例：

```sh
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

1. 「音声ファイルを選択」からパイロット役の音声（wav/mp3等）をアップロード
2. 中央パネルの5種のゲージでノイズ強度（0〜100%）を調整
3. 「ノイズ適用 再生」で劣化させた音声を再生（「原音 再生」で元音声も確認可）
4. 右パネルの「お気に入り」に劣化パターンを3枠まで保存し、訓練中はワンクリックで呼び出し
5. 下部「訓練シナリオ」で、聴取内容と応答文を記入。あらかじめ模範解答を登録しておけば、
   「解答を表示」で答え合わせができます

## ノイズエフェクト

| エフェクト | 内容 |
|---|---|
| マスク籠り | 酸素マスク越しのようなローパス＋こもり共鳴 |
| 無線ノイズ | 帯域制限・ソフトクリップ歪み・ヒスノイズを付加した無線機越しの音質 |
| 風切り音 | 低域ノイズとゆったりしたゲイン変動によるゴウという風切り音 |
| 英語の訛り（簡易再現） | フォルマント帯域の強調位置をずらし、抑揚・リズムを揺らす簡易近似。<br>実際の音声変換ではなく、聴感上の違和感を再現する近似効果です |
| 通信不良（音声途切れ） | ランダムな間隔・長さで音声を瞬断させ、スケルチ切れを再現 |

すべてブラウザ内蔵の Web Audio API（`OfflineAudioContext`）でその場合成しており、
音声ファイルや訓練データは外部送信せず、ブラウザ内（`localStorage`＝お気に入り設定のみ）に留まります。

## 構成

- `index.html` — 画面構造
- `css/styles.css` — UIスタイル（管制コンソール風デザイン）
- `js/audioEngine.js` — ノイズエフェクトのDSP処理
- `js/presets.js` — お気に入り設定の保存・読み込み（localStorage）
- `js/app.js` — 画面の配線・再生制御・訓練パネルのロジック
