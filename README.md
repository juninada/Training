# JASDF R/T TRAINER — 航空無線通信 聴取判断訓練システム

航空自衛隊の管制官を想定した、無線交信の聴取訓練 Web アプリです。
アップロードした音声にリアルタイムでノイズエフェクトをかけて再生し、
「相手（パイロット）は何を話しているか」「自分は管制官として何を応答すべきか」
を判断する訓練を行います。

すべてブラウザ内（Web Audio API / IndexedDB / localStorage）で完結する
静的サイトのため、サーバーサイド実装は不要です。

## 使い方

1. `index.html` をブラウザで直接開くか、任意の静的サーバーで配信します。
   ```bash
   python3 -m http.server 8000
   # http://localhost:8000/ にアクセス
   ```
2. **SCENARIO LIB** タブで、練習用の音声ファイル・パイロットの発話書き起こし・
   模範応答（管制官として返すべき内容）を登録します。
3. **TRAINING** タブでシナリオを選び、右側のノイズエフェクトをオン/強度調整し、
   「①ノイズ適用」→「▶ 再生」で聴取します。
4. 聴取内容と自分の応答を入力し、「解答照合」で模範解答と突き合わせます。
5. よく使うノイズ設定は「お気に入りプリセット」に保存し、次回からワンクリックで
   呼び出せます（最大3件）。

## ノイズエフェクト

| エフェクト | 内容 |
|---|---|
| マスク籠り | 酸素マスク越しのような高域減衰（ローパスフィルタ） |
| 無線ノイズ | 通信帯域のバンドパス＋歪み＋ホワイトノイズのベッド |
| 風切り音 | ピンクノイズ＋周期変調によるコックピット風防音風の風音 |
| 英語訛り | フォルマント強調EQ＋軽いコーラスで声質のゆらぎを演出 |
| 通信途切れ | ランダムなドロップアウト区間とスケルチ音での通信不良再現 |

各エフェクトは0〜100%のゲージバーで強度を調整でき、複数エフェクトを重ねて
実践に近いノイズ環境を再現できます。

## 構成

```
index.html        画面構成（TRAINING / SCENARIO LIB タブ）
css/style.css     JASDFをイメージしたネイビー×アンバー×シアンのHUD風デザイン
js/audio-engine.js  OfflineAudioContext によるノイズエフェクト生成・レンダリング
js/storage.js       IndexedDB(シナリオ) / localStorage(お気に入りプリセット)
js/app.js           UI制御・トレーニングフロー
```

## 動作環境

Web Audio API（OfflineAudioContext）と IndexedDB をサポートするモダンブラウザ
（Chrome / Edge / Firefox 最新版）で動作します。
